# Docker + Docker Compose Installation Script

## Overview
This script automates the installation of Docker and Docker Compose on **all major Linux distributions**, including:

- Ubuntu, Debian, Linux Mint, Kali, Proxmox
- RHEL, CentOS, AlmaLinux, Rocky Linux, Oracle Linux, Amazon Linux, Fedora
- SLES, openSUSE
- Alpine Linux
- Arch Linux, Manjaro
- CloudLinux

## Prerequisites
- Any Linux distribution (list above)
- Root or sudo access
- Internet connection

## Quick Installation

Download and run the script with one command:

```bash
curl -O https://raw.githubusercontent.com/sumit-kumawat/docker-compose/main/install.sh
chmod +x install.sh
sudo bash install.sh
